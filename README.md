📊 Amazon Sales Analysis Dashboard (Power BI)
📌 Project Overview
This project is an Amazon Sales Analysis Dashboard built using Microsoft Power BI.
The dashboard provides interactive insights into Amazon product sales, helping users analyze performance across products, locations, order status, and time.
It is designed to support data-driven decision-making by presenting key sales metrics in a visually appealing and easy-to-understand format.

🎯 Objectives
Analyze overall Amazon sales performance
Track total sales, units sold, and seller count
Understand sales distribution by city and state
Monitor order status (Shipped, Cancelled, Returned, etc.)
Identify sales trends over time (Year, Month, Day)

📈 Dashboard Features
🔹 Key Metrics (KPIs)
    Total Sales
    Units Sold
    Seller Count

🔹 Interactive Filters
    Product category selection
    Order status filter
    Date-based filtering (Year / Month / Day)

🔹 Visualizations
    Sales by City (Bar Chart)
    Sales by State (Bar Chart)
    Sales Trend Over Time (Area Chart)
    Product-wise sales overview
    Status-based sales analysis

🛠 Tools & Technologies
  Microsoft Power BI
  DAX (Data Analysis Expressions)
  Power Query
  Data Modeling
  Data Visualization Techniques


🚀 How to Use
    Download the .pbix file from the repository
    Open it using Power BI Desktop
    Use filters and slicers to explore the data interactively

📌 Future Enhancements
    Add profit and cost analysis
    Include customer segmentation
    Forecast future sales using time series analysis
    Publish to Power BI Service for live reporting
